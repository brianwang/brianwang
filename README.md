## 代表项目

**[BIMCraft](https://github.com/brianwang/bimcraft-showcase)** — 用纯 Rust 从零实现的 BIM 工作流，可被 agent 通过 MCP 驱动。自研几何内核、2D/3D 渲染、IFC 读写、族系统、跨平台打包。早期开发，源码私有。

**[China Web Agent Bench](https://github.com/brianwang/cn-web-agent-bench)** — 中文互联网平台的 agent 评测集。10 个真实任务，首轮成功率 37%，量化了登录墙、反自动化、动态渲染这些英文基准没有覆盖的障碍。

**[session-keeper](https://github.com/brianwang/session-keeper)** — 多平台浏览器登录态管理。持久化 profile、过期检测、headed 重登引导，解决自动化里最长尾的登录失效问题。
